The Brand

Keep the name. Sharpen everything around it.

GradingStamps.com stays the brand. It's an exact-match domain that says the product in one word, it has age and inbound links Google already trusts, and teachers can spell it over the phone. “MJ's Art Stamps” shouldn't disappear, though — it becomes the maker's mark: “From MJ's Art Stamps, serving teachers for 20+ years” in the header byline and footer. That story — a real family business with 35 years of classroom experience — is the thing big stamp retailers can't copy, so the new site says it out loud.

The voice writes teacher-to-teacher: plain, warm, a little wry (the products are cartoon dogs and snails — the site shouldn't sound like enterprise software). The old site already had the perfect tagline buried in its hero copy; we just tighten it:

Stop writing. Stop explaining.
Start stamping.

Supporting claims, straight from the product's real specs: 20,000 impressions before re-inking · no ink pads, no mess · Austrian-made mounts, assembled in the USA.

The Artwork

Refresh the images — without redrawing the product

One rule governs everything here: the image is the product. A customer receives a stamp that prints exactly this art, so an AI that “improves” the drawing is misrepresenting the merchandise. The fix isn't generation — it's vectorization. The catalog is black-and-white line art, the single best case for tracing to SVG. Here's a real conversion from today's files, not a promise:

Then add one thing the old site never had: a real photo of the physical pre-ink mount, shot once and reused across all products so buyers see the object, not just the impression.
The Checkout

A cart without a server

Static sites can absolutely sell things — the cart just lives with a payment provider instead of on your server. For a 56-product, single-variant catalog:

OptionCostFit
Stripe Payment Links ✓ $0/mo · 2.9% + 30¢ per sale One hosted link per stamp; handles cards, Apple/Google Pay, shipping address collection, receipts. Zero code to maintain — the recommendation.
Etsy shop (exists already?) $0.20 listing + ~6.5% + processing Pricier per sale, but brings its own buyers searching “teacher stamps.” Worth keeping alongside the site if shop 6652717 is still alive — needs confirming.
PayPal buttons $0/mo · ~2.99% + fixed Familiar to the retired-teacher demographic; easy to add next to Stripe later.
Shopify / Snipcart $5–39/mo Recreates the monthly-bill problem we're escaping. Pass.

The Flash generator's replacement: a simple custom-stamp request form — describe the stamp, upload artwork, pick a size — submitted through a free form service (Web3Forms/Formspree) straight to CustomerService@GradingStamps.com with a quote to follow. That matches how custom orders actually get finalized anyway. A fancy in-browser designer can be a phase-two toy if the shop earns it.

The Stack

Boring technology, free hosting

Astro (or plain Eleventy) builds the whole site from products.json at deploy time — 60-odd pure-HTML pages, zero JavaScript shipped except the cart button. Hosted on Cloudflare Pages (free tier: unlimited bandwidth, global CDN, automatic HTTPS — fixing the “Not secure” warning on day one). Point the domain there, keep the registrar, cancel the Windows hosting.

SEO

Built into the pages, not bolted on

  • One URL per stamp — /stamps/excellent-dog-a171/ — so every product can rank for its own searches (“excellent dog rubber stamp”, “late work stamp for teachers”).
  • Product + Offer structured data (JSON-LD) on every product page: name, image, price, availability → eligible for Google Shopping-style rich results.
  • Titles & meta descriptions generated from the real scraped copy; descriptive alt text from each stamp's keywords.
  • Category landing pages matching how teachers search: grading stamps, homework stamps, Spanish teacher stamps, parent-signature stamps.
  • sitemap.xml, canonical tags, Open Graph cards, and 301 redirects from every old .aspx URL so 15 years of link equity transfers instead of evaporating.
  • Core Web Vitals essentially perfect for free — static HTML + SVG art is as fast as the web gets, and speed is a ranking factor.
The Roadmap

Five steps to shut off the server

  1. Approve the direction

    This document: brand, palette, type, checkout choice. Anything here is swappable now, expensive later.

  2. Vectorize the catalog

    Batch-trace all 56 stamps to SVG; AI-upscale the shaded few; photograph one pre-ink mount.

  3. Build the static site

    Astro templates fed by products.json — home, shop with filters, 56 product pages, custom-request form, contact.

  4. Wire up money

    Create Stripe Payment Links per stamp; confirm/link the Etsy shop; test an end-to-end order.

  5. Launch & cancel

    Deploy to Cloudflare Pages, point the domain, 301-map the old URLs, verify in Search Console — then cancel the Windows hosting and pocket the $300/yr.
